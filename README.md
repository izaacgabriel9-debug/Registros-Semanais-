📝 Resumo da Semana
 
- Aula 1: Aprendi sobre a estrutura e sintaxe do HTML, além de revisar e fixar os 3 elementos fundamentais da programação: entrada, processamento e saída.
- Aula 2: Estudei códigos práticos de HTML e JavaScript, aprendi a escrever corretamente a sintaxe das duas linguagens, como criar variáveis e constantes, e compreendi o funcionamento dos operadores lógicos. Na prática, construímos códigos dentro da estrutura do arquivo  index.html  com JavaScript.

📖 Explicação Técnica
 
Sintaxe e estrutura HTML: É o conjunto de regras e a ordem correta para escrever o código de uma página. Usamos tags para definir cada parte do conteúdo, e a estrutura segue uma ordem lógica para funcionar nos navegadores.
 
3 Elementos da Programação: São a base de qualquer programa: Entrada (dados recebidos), Processamento (cálculos ou manipulações) e Saída (resultado exibido). Tudo o que criamos segue essa lógica.
 
Variáveis, Constantes e Operadores Lógicos:
 
- Variáveis são espaços para guardar dados; constantes são valores que não mudam.
- Operadores lógicos servem para comparar valores e tomar decisões dentro do código.
-  let : cria variável que pode ser alterada;  const : cria valor fixo;  var : forma antiga de criar variável. Todos armazenam números, textos, etc.
 
Shell e GUI:
 
- Shell: interface por texto, onde digitamos comandos para controlar o sistema.
- GUI: interface gráfica, com janelas, ícones e botões, usada com mouse e teclado.
 
Comandos Linux/Unix:
 
-  cd : navega entre pastas/diretórios.
-  ls : mostra todos os arquivos e pastas que estão no local atual.
-  mkdir : cria uma nova pasta.
-  touch : cria um novo arquivo vazio (ex:  index.html ).
 
Cálculo de média em JavaScript: Usamos variáveis para guardar os 3 números, somamos os valores, dividimos por 3 e mostramos o resultado — aplicando entrada, processamento e saída na prática.
